Repositório com as minhas resoluções dos exercícios do curso de Python do
[Curso em Vídeo](https://www.cursoemvideo.com/), do professor Gustavo Guanabara,
do Mundo 1 ao Mundo 4.

## 📚 Conteúdo

- **Mundo 1:** fundamentos (tipos primitivos, operadores, strings, módulos)
- **Mundo 2:** estruturas de controle (condições e laços de repetição)
- **Mundo 3:** estruturas de dados (tuplas, listas, dicionários), funções e tratamento de erros
- **Mundo 4:** Programação Orientada a Objetos

## 📁 Estrutura

Os exercícios estão organizados por mundo e por aula, em pastas separadas.
Cada arquivo segue o padrão `NN - Nome do exercício.py`.

## ▶️ Como executar

    python3 "nome_do_arquivo.py"

Alguns exercícios usam bibliotecas externas (por exemplo, o `pygame`):

    pip3 install pygame

## 🎯 Objetivo

Praticar lógica de programação e acompanhar a minha evolução nos estudos.
